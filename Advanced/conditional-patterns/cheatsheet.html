Advanced Conditional Patterns

Common gap patterns on the LSAT: how to spot each one and what fills it.

Notation: A → B means if A, then B. /A means not A.
Every pattern: premise and conclusion first, then find what links them.
P → C Bridge
Spot it
One premise. The conclusion jumps to a new idea.
The gap
The link from the premise to the conclusion.
PremiseP
ConclusionC
GapP → C
Shared Sufficient
Spot it
Premise and conclusion share the same sufficient, but end in different necessaries.
The gap
Connect the two necessaries, from the premise to the conclusion.
PremiseA → B
ConclusionA → C
GapB → C
Line Up the SufficientTactic
Spot it
There's a shared term, but it isn't in the sufficient in both.
Do this
Take the contrapositive of whichever one has it in the necessary. Then connect the two necessaries.
PremiseA → /B
B → /A(contrapositive)
ConclusionB → C
Gap/A → C
Link the Premises
Spot it
No new idea in the conclusion. Its sufficient and necessary both already show up in the premises.
The gap
Link where premise 1 ends to where premise 2 starts.
Trap: the reverse link (C → B). It leaves you stuck at B.

Premise 2C → D
ConclusionA → D
GapB → C
Trigger the Rule
Spot it
A rule in the premises, a conclusion that uses it, but nothing triggers it.
The gap
The trigger: the sufficient happened, or the necessary didn't.
