Argument Part

STEP 1
Read the Question Stem
  • Identify the referenced sentence
  • Underline or highlight it
↓
STEP 2
Read the Stimulus
  • Label each sentence: conclusion, support, background
  • Understand the passage fully
↓
STEP 3
Describe the Referenced Sentence
  • Predict: What is its function in the argument?
↓
STEP 4A
If You Have a Prediction
  • Go into Hunt Mode
  • Start with answer choices that match
STEP 4B
If No Prediction
  • Go through each answer sequentially
↓
STEP 5
Evaluate & Select
  • Ask: Does this capture the role of the sentence?
  • Pick the best description
↓
Correct Answer Check
Descriptively accurate · Every word reflects the stimulus
